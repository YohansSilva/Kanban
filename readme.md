
#Kanban/trello

Um sistema de gerenciamento de tarefas inspirado em ferramentas como Trello, desenvolvido do zero com **HTML, CSS e JavaScript puro**.

O projeto foi criado como parte do meu portfólio para praticar manipulação do DOM, eventos, criação dinâmica de elementos e Drag & Drop.

>**Projeto em desenvolvimento:** novas funcionalidades serão adicionadas ao longo do tempo.

---

## Funcionalidades

### Colunas

- [x] Criar novas colunas
- [x] Editar nome da coluna
- [x] Alterar a cor da coluna
- [x] Adicionar cards dentro das colunas

### Cards

- [x] Criar cards dinamicamente
- [x] Editar cards
- [x] Título
- [x] Descrição
- [x] Prioridade
- [x] Indicador visual de prioridade
- [x] Botão de edição

### Drag & Drop

- [x] Arrastar cards
- [x] Mover cards entre diferentes colunas
- [x] Feedback visual durante o arraste
---

##  Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
- Font Awesome

O projeto atualmente não utiliza frameworks ou bibliotecas JavaScript, com o objetivo de praticar e demonstrar conceitos fundamentais do JavaScript e do DOM, maior parte aprendi na Fatec.
